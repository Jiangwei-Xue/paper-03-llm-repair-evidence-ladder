This package uses a layered license rather than a single repository-wide license.

| Material class | License or governing terms |

| Original project documentation and author-created derived tables | CC BY 4.0 |
| Original analysis, replay, validation, and utility code | MIT |
| Manuscript | author copyright; publicly licensed under CC BY 4.0 as recorded by Zenodo |
| Third-party libraries, benchmark-derived records, public data, and model output | original applicable terms |

`LICENSE.md` is the controlling package-level map. The notices under `LICENSES/`
provide the referenced CC BY 4.0 and MIT texts. `paper/LICENSE.md` records the
manuscript-specific grant. `THIRD_PARTY_NOTICES.md` records the boundary for
externally governed materials.

The presence of a file in this repository does not itself change the file's
governing terms. In particular, historical prompts, model outputs, provider
metadata, benchmark-derived records, and Docker/OCI identity records are not
relicensed as CC BY 4.0 or MIT merely because they are redistributed in a text,
JSON, JSONL, CSV, or Markdown representation.
