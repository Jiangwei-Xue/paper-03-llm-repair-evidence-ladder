# Artifact Boundary

## Included

- current manuscript source and compiled PDF;
- canonical 2,400-row analysis table and deterministic claim view;
- generated result tables and deterministic analysis code;
- five historical run ledgers and their run configurations/plans;
- E5/VCR row ledgers, replay indexes, and offline integrity checks;
- provider-control, weak-oracle, and Docker-provenance evidence;
- identity and retained configuration metadata for 60 task images;
- retained experiment-code snapshot and integrity verifier;
- frozen protocol records, extension sampling/admission evidence, and prompt audits;
- layered licensing and third-party notices.

## External dependencies

- Docker image layers and third-party repository snapshots;
- benchmark support files and protected verifier material;
- hosted-model weights and provider-side inference infrastructure;
- complete large per-attempt prompt/response/verifier payload archives;
- credentials and service accounts;
- dependency packages fetched during optional environment reconstruction.

## Supported claims

The package supports recomputation of manuscript tables from saved canonical rows,
validation of E5/VCR row and replay links, analysis-code checks, Docker metadata
verification, source compilation, and archive-integrity verification.

It does not claim that offline replay is a fresh model/API run, that Docker
metadata substitutes for image layers, that hosted responses can be regenerated
bit-for-bit, or that local verifier pass proves complete developer-intent
correctness. New external executions must be reported as new evidence strata.
The row and replay indexes in this package do not imply that every referenced
large raw-attempt artifact is distributed here.
