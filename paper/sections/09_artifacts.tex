The public reproduction package is maintained at \url{\ArtifactURL}. It
provides the manuscript source; the canonical 2,400-row
claim table and 300 fixed-cell view; deterministic analysis code for rebuilding
the reported tables; frozen protocols, configurations, and task manifests; the
public H5/E5/VCR row ledgers and hash relationships; full-transcript
prompt-visibility audit reports; provenance and release records; retained
configuration metadata for 60 task-specific Docker images; and the experiment
harness, live runners, strict edit-transport implementation, answer-state
contract, and local contract tests needed to inspect the recorded evaluation
path. The package also supplies documented offline commands for validating the
evidence chain, regenerating claim-bearing analyses, and recompiling this
manuscript.

The release does not redistribute Docker image layers, third-party repository
snapshots, protected verifier material, private provider payloads, hosted-model
weights, or credentials. The public E5/VCR records establish the released
row-level relationships and integrity boundaries, but omitted private artifacts
cannot all be dereferenced from the public package. Accordingly, the release
supports deterministic offline evidence replay, analysis, and source-level
inspection; it does not claim bitwise regeneration of historical hosted-model
outputs or a self-contained fresh provider-and-Docker rerun.
